# Mulier Gestión

Sistema de gestión comercial desarrollado para Mulier, un emprendimiento dedicado a la venta de indumentaria, ropa interior y productos de belleza.

## Objetivo del proyecto

Desarrollar una aplicación que permita organizar y simplificar la administración del negocio.

## Funcionalidades principales

- Registro y administración de clientes.
- Registro de ventas.
- Seguimiento de saldos pendientes.
- Registro de pagos realizados por los clientes.

## Futuras funcionalidades

- Control de stock.
- Gestión de productos.
- Reportes de ventas.

## Tecnologías

- C#
- .NET
